# Prompts by Robert DeVore

The source for [prompts.robertdevore.com](https://prompts.robertdevore.com), a curated library of reusable AI prompts.

The site is generated by [Kujo SSG](https://github.com/kujolang/ssg) and styled with the vendored [SiteKit](https://github.com/kujolang/site-kit) distribution. It keeps the original site's black, white, and yellow visual identity while using Departure Mono, responsive layouts, local search, accessible navigation, RSS, sitemap, `llms.txt`, and automated GitHub Pages deployment.

## Local development

Install the `kujo` CLI, then run:

```bash
./scripts/build.sh
kujo serve output --port 4178
```

Open <http://127.0.0.1:4178>.

Use the production URL for a release build:

```bash
SITE_URL=https://prompts.robertdevore.com ./scripts/build.sh
```

Generated files are written to `output/` and are never edited or committed directly.

## Content

- `content/posts/`: prompt articles rendered under `/blog/<slug>/`
- `content/pages/`: standalone pages such as `/contact/`
- `assets/images/`: article and listing images
- `templates/`: Kujo SSG HTML templates
- `assets/css/style.css`: site-specific styles composed from SiteKit tokens
- `assets/sitekit/`: the complete, unmodified SiteKit consumer distribution
- `static/`: files copied to the root of the generated site

Add a post as Markdown or HTML-flavored Markdown with frontmatter:

```yaml
---
title: A useful prompt
description: What the prompt helps create.
custom_url: useful-prompt
date: 2026-08-08
author: Robert DeVore
tags: [json prompts, design]
featured_image: /assets/images/useful-prompt.webp
---
```

## Verification

```bash
bash scripts/test-site.sh
```

The test builds the production site, validates generated HTML, confirms all legacy routes, checks migrated content and media, and verifies SiteKit and Departure Mono are present.
