# Research sources

Audit date: 2026-09-16

| Source | Retrieved | Supported conclusion | Classification |
| --- | --- | --- | --- |
| [Google: Search developer guide](https://developers.google.com/search/docs/fundamentals/get-started-developers) | 2026-09-16 | Important pages should use crawlable links, descriptive titles/descriptions, semantic HTML, accessible DOM text, and valid structured data. | Official recommendation |
| [Google: SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) | 2026-09-16 | Titles and descriptions should be unique and useful; relevant images should be clear and placed near relevant text; user usefulness outranks mechanical scoring. | Official recommendation |
| [Google: Build and submit a sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) | 2026-09-16 | A sitemap should contain canonical URLs and should reflect significant page changes. | Official recommendation |
| [Google: Structured data introduction](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data) | 2026-09-16 | JSON-LD can clarify page meaning and eligibility, but does not guarantee a rich result. | Official documentation |
| [Google Search Console performance report](https://support.google.com/webmasters/answer/7576553) | 2026-09-16 | Clicks, impressions, CTR, and average position must come from property data and can be segmented by query/page/device/country. | Official measurement guidance |
| [Google: PageSpeed Insights](https://developers.google.com/speed/docs/insights/v5/about) | 2026-09-16 | Lab Lighthouse results and 28-day CrUX field data are different evidence; insufficient CrUX data must not be inferred. | Official measurement guidance |
| [Bing Webmaster Guidelines](https://www.bing.com/webmasters/help/bing-webmaster-guidelines-30fba23a) | 2026-09-16 | Crawlable internal links, canonical consolidation, and timely URL-change notification support Bing and Copilot discovery/grounding. | Official recommendation |
| [Bing: IndexNow](https://www.bing.com/webmasters/help/indexnow-0z209wby) | 2026-09-16 | IndexNow can notify participating engines about added, updated, or deleted URLs; actual indexing still requires platform evidence. | Official optional protocol |
| [OpenAI publisher FAQ](https://help.openai.com/en/articles/12627856) | 2026-09-16 | OAI-SearchBot access is required for content inclusion in ChatGPT summaries/snippets; GPTBot training policy is a separate owner decision. | Official crawler guidance |
| [Perplexity crawler documentation](https://docs.perplexity.ai/docs/resources/perplexity-crawlers) | 2026-09-16 | Perplexity recommends allowing PerplexityBot for search appearance and distinguishes it from model-training use. | Official crawler guidance |
| [Schema.org BlogPosting](https://schema.org/BlogPosting) | 2026-09-16 | BlogPosting is an appropriate vocabulary type for the site's dated prompt articles. | Official vocabulary |
| `llms.txt` and static WebMCP | 2026-09-16 | Useful experiments for machine discovery, but neither is treated here as a documented search-ranking requirement. | Experimental/emerging practice |
