Use this prompt after an AI coding agent finishes a feature, fix, or optimization. It asks the agent to read the actual code and development evidence, then teach you how the changes work and which ideas you can reuse in your next project.

## How to Use It

Paste the complete prompt into an assistant with access to the project. Point it to the relevant commit range, pull request, or changed files so it can focus on the completed work. Include test results or benchmark data if you have them. The prompt asks the assistant to distinguish verified facts from interpretations and to identify gaps in the evidence.

## What the Tutorial Covers

Expect a walkthrough of the project's architecture and representative code, explanations of design tradeoffs, and exercises with ways to verify your work. The assistant can add diagrams, interactive examples, or a portable learning record when the evidence and environment support them.
